🎮 Tic-Tac-Toe Game in C++

A simple console-based Tic-Tac-Toe game developed using C++.

The game allows two players to enter their names, choose their symbols (X or O), and play against each other on a 3×3 game board.

✨ Features

* 👥 Two-player mode
* ✏️ Players can enter their names
* ❌⭕ Players can choose between X and O
* 🎮 Interactive 3×3 game board
* 🚫 Input validation for invalid positions
* 🔒 Prevents players from choosing an already occupied position
* 🏆 Automatically detects the winner
* 🤝 Detects draw games

🛠️ Concepts Used

* C++
* Functions
* Arrays
* Loops
* Conditional Statements
* Input Validation

▶️ How to Play

1. Enter the names of both players.
2. Player 1 chooses either X or O.
3. Players take turns choosing a position from 1 to 9.
4. The first player to complete a row, column, or diagonal wins.
5. If all positions are filled without a winner, the game ends in a draw.

📚 Purpose

This project was created to practice basic C++ programming concepts such as functions, arrays, loops, conditions, and user input.
